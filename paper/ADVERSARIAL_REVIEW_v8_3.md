## 2. Adversarial attacks

### A. “The graphics will be unreadable in IEEE two-column format.”

Resolved at the source-master level. The v8.3 figures are full-width two-column designs with minimum reproduced text ~9.23 pt. The older v8 graphics would have produced ~5–6 pt body text and are therefore superseded for submission layout.

### B. “The figures merely duplicate tables.”

Resolved. Fig. 2 now visualizes paired differences and intervals; Table II carries exact absolute values. Fig. 3 uses evidence-class cards; Table III carries exact gate/numerical text. The graphics and tables have different jobs.

### C. “The presentation hides adverse evidence.”

Not supported. The Anti-UAV profile disadvantage, R5 edge-hit interval crossing zero, IDF-DS source stop, AMOVFLY endpoint limitation, and design-regeneration drift all remain visible in the main paper or explicitly signposted Supplement.

### D. “IDF-DS should be removed because it has no performance result.”

Rejected. It is not counted as method-performance validation. It supports the fail-closed source-eligibility gate and is labelled as a stop before outcome opening.

### E. “The paper overstates external engineering validation.”

Not supported under the current wording. Anti-UAV is a task-effectiveness transfer result with execution clarification. AMOVFLY is a numerical confirmation with endpoint-semantic limitation. Neither is presented as weapon-system certification or unrestricted qualification evidence.

### F. “The manuscript cannot yet be called journal-ready because SVG is not an IEEE final graphic format.”

Accepted as a packaging issue. SVG remains the canonical reproducible vector master. PDF/EPS export with embedded fonts is required only after the exact target template is frozen. This is a non-scientific blocker, not a research blocker.
